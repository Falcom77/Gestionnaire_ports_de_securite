⚠️ Le tableau est vide ?

C'est normal si vous avez double-cliqué sur index.html

Solution : Lancez un serveur local (2 minutes)

📋 Étapes d'installation

1 Ouvrez un Terminal / Invite de commandes
  • Windows : Recherchez "cmd" ou "PowerShell"
  • Mac : Ouvrez "Terminal"
  • Linux : Ctrl+Alt+T
2 Naviguez vers le dossier standalone_app
cd /chemin/vers/standalone_app
Remplacez par le chemin réel de votre dossier
3 Lancez le serveur local
python3 -m http.server 8000
Sur Windows, essayez: python -m http.server 8000
4 Ouvrez votre navigateur

Allez sur : http://localhost:8000/

✅ C'est tout !

Vous devriez maintenant voir :

  • 67 services/ports affichés
  • 6 périphériques dans le parc informatique
  • Toutes les fonctionnalités actives

💡 Astuce

Une fois les données chargées, elles sont sauvegardées dans votre navigateur. Vous pourrez ensuite ouvrir index.html directement sans serveur.
